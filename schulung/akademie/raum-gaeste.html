02Try the chatYou see the chat the way a guest will see it.5 functions
  1. «Try the chat» at the top right opens a window: four questions to tap, and the chat as a guest sees it on the phone.

  3. A question sent from here lands in the inbox as an example.

03InboxGuests who send a question and leave a contact are in the inbox.4 functions
  1. «All», «New», «Open» and «Done» filter the list. Inquiries are sorted by day.
  2. Opening an inquiry marks it as read. It shows the contact, when it was sent, from which page, and the question.
  3. «Done» marks an inquiry as answered. «Open again» brings it back.
  4. Inquiries are kept for twelve months. The bin button and «Delete for good» delete one when a guest asks for it.

04Personal replyUnder the question is a sheet with the logo for a reply to one guest.5 functions
  1. Write the reply into the sheet.
  2. «Save reply» (Ctrl+S, on a Mac ⌘S) keeps it with the inquiry.
  3. «Copy text» puts the reply on the clipboard. You send it yourself by phone, message or Instagram.
  4. Nothing is sent from the tool, and no mail program opens.
  5. If two windows save the same inquiry, the second gets «changed in another window». Nothing is overwritten.

05Questions and answers for every guestEvery question guests sent stands here by topic.7 functions
  1. «Questions» shows all questions, without answer, answers by you and with contact.
  2. «Without answer» shows only the questions that still need you.
  3. «Answer for every guest» opens a form for one answer that the chat gives to everyone after «Publish».
  4. «Other ways guests ask» takes other words, with commas, for example toilet, restroom.
  5. «Valid until» ends an answer on a date. Leave it empty for no end.
  6. «Mark as done without answer» is for questions that do not fit the house.
  7. Questions marked «Example» are samples until real ones come in.

07What the chat knowsThe chat only answers with the lines here.7 functions
  1. Lines come from the website (opening hours, address, phone, menu, drinks, the pool table, the playground, events) and from you.
  2. Tap a line, change the text, «Save». The website itself stays as it is.
  3. «Hidden» stops the chat from saying a line. «As on the website» brings back the original line.
  4. «Valid until» sets a date after which the chat no longer says the line.
  5. «Something new» or «Add a line» adds a line with title, text, area and an optional photo.
  6. The search field searches all areas.
  7. «Ask, like a guest» answers from the draft. The question is not saved.

08Publish and earlier versionsEverything you save goes into the draft first. Guests see it only after «Publish».7 functions
  1. The bar at the bottom shows «Draft: n changes wait».
  2. «Before, after» lists each change: new, changed, removed or hidden.
  3. «Publish» opens a window with the list and a note. «Publish now» writes the answers file of the chat again. The website pages stay as they are.
  4. When it is done: «It is online.» If something goes wrong, the old answers file stays.
  5. «Earlier versions» lists each version with date, number of answers and note. «Original state» holds the answers from the website.
  6. «Put in the draft» changes nothing on the website until you publish.
  7. «How the chat works» shows the way of a question in eight steps, with the numbers of today.
