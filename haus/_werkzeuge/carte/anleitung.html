Menus & price lists of The Cat & Gun.

Here you keep the dishes, drinks and prices of The Cat & Gun: Drinks, Coffee & juices and Kitchen, with the same pages, sections and order as the printed menu in the café. From the same data come the PDF for the printer and the menu page of the website. The menu in the café is printed on boards and cannot be swapped. A change here is for the next printed menu and for the website. The boards stay as they are.

How it works

  1. Who works? Until handover the log says «Team The Cat & Gun», without a login. After that a login comes first: kitchen and service change the menus and print test PDFs, the manager publishes, brings back earlier versions and switches the website link.
  2. The menus: the tool opens with the overview. Drinks, Coffee & juices and Kitchen are the tabs under the title. In a menu the preview on the left shows it as it will be printed, the list is on the right. On the phone the list comes first, the preview below it, and the button at the top right opens the side panel with all tools.
  3. Simple: One click on an item shows it in the list and in the menu at the same height, and it flashes briefly. Double-click or the pencil opens it: name, marks (V, R), price, the second price line where there are two (Bagel, Focaccia), description. Copy makes a new item in the same format, the eye hides it for a while, the bin takes it away, the arrows change the order. «New item» and «Add item» at a section add an item at the end of a section, «New section» adds a section. Prices are written like on the menu: «260», «220/GLASS» or «240 | 260».
  4. Advanced: On a computer or tablet only; the phone has «Simple». You design right on the menu. One click picks a text, an item, the logo or the footer. Drag to move, use the corners to make it bigger or smaller, it snaps to edges and centres (guide lines; not with the Alt key held). On the right «Design» opens: font, size, text style (normal or capitals), colour, alignment, line spacing, space before and after. A double-click writes straight into the text. «Menu data» shows the pages of the menu as text.
  5. Menu or website: Switch above the preview. «Website» shows the menu page with your draft, the way a guest will see it after publishing.
  6. Draft: Nothing is saved silently. Every change is a draft first (button «Save» below, then green). PDF and website change only when you publish.
  7. Before, after shows each place on the left (today) and on the right (draft), new words marked. Test PDF prints the draft to look at.
  8. Publish prints the PDF, compares it word for word with the data, builds the website pages with the new menu and only then replaces the old version. The last version stays under «Earlier versions».

Keys

  • ⌘Z undoes, ⌘⇧Z or ⌘Y redoes (also text you wrote).
  • ⌘S saves, also while writing in the menu.
  • Arrow keys move the chosen part by 0.5 mm, with Shift by 5 mm.
  • Delete hides the chosen part, Esc unselects.

«Short tour» in the side panel shows in a few steps where things are.

What happens on the website

The website is not online yet. Until then menus & price lists works for itself: «Publish» makes the PDF for the printer and builds the menu page of the website with the new menu. This page waits in the tool, ready to go online. The website itself stays as it is. When the website is online, the website link puts it in place in the same step.

What to do if …

Every message carries a keyword. Here is what it means and what to do. The state of browser, server, menus and backups is on the check page.

KONFLIKT

Someone else changed the menu in the meantime. Reload the page, then look at their change. Your input waits in the tool, marked yellow.

PASST

Not everything fits on the pages. Shorten or hide an item, or move it to another page, then publish again. Nothing was changed.

PDF

A text of the menu is missing in the printed PDF. Nothing was published. The message names the place. The test PDF usually helps.

DRUCK

The PDF could not be printed. Nothing was changed. The check page shows what is missing under «Printing and checking the PDF». Try once more. If it stays, call support.

WEBSITE

The menu page of the website could not be built with this menu. Nothing was published. Call support.

RECHT

This role cannot do this. Please ask the manager.

ROLLE

The tool does not know the role. Reload the page. If it stays, call support.

PRUEF

An input is not allowed, for example program code in a text or a menu without pages. The message says which.

GRENZE

Too many requests in a short time. Wait a minute.

KAPUTT

A file of the menu is damaged and there is no backup. Stop editing this menu and call support. Otherwise the tool brings back the last good version by itself and logs it.

BAU

Another menu is being published right now. Wait a moment.

VERBINDUNG

The browser cannot reach the tool right now (no network or the server is off). Your input is still here. When the network is back, press «Save» again. Do not reload, or unsaved input is lost.

HERKUNFT

The change did not come from the tool itself, for example from another page. It was refused. Open the tool directly and change it there.

HOST

The tool was opened under a strange address and did not answer. Use the address from the Control panel.

FORM

The request did not have the expected form. Reload the page. If it stays, call support.

GROSS

The data is bigger than 3 MB and was not accepted. Usually a very long pasted text: shorten it and save again.

ZIEL

This menu does not exist. Pick one of the three menus in the overview.

DATEI

The file or version does not exist (or not yet, for example before the first test PDF).

LEER

A menu has not been read in yet. Call support.

SCHEMA

The menu comes from a newer version of the tool. Change nothing and call support.

PRUEFWERK

The program that checks the printed PDF word for word is missing. Nothing is published without this check. Call support.

ANSCHLUSS

The new website pages could not be put on the website unchanged. The menu itself is published. The website still shows the last pages (kept under «Earlier versions»). Open the check page and call support.

DEMO

This comes when the website goes online, for example the website link. Until then the website stays as it is. Everything works in the tool.

WEG

Unknown request. Reload the page.

SERVER

Something went wrong in the server. The details are in the error log for support.
